## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Installation

### 1) install docker
### 2) open terminal inside project folder
```bash
$ docker-compose up
$ npm install
$ npx prisma init
$ npx prisma db push
```

## Running the app
```bash
# development
$ npm run start
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
